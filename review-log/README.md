# review-log/ · 审核留痕（append-only）

「谁、在什么时候、**凭什么**」把一条技能放进公共目录 —— 这是本目录的信任基础。自 v4 起，留痕由 CI 强制。

## 规则

- **append-only**：已写入的裁决不得删改。要更正就**追加**一条新裁决（同一 `id` 新日期覆盖旧状态），并在 `note` 里写明「更正了哪条、为什么」。
- **一个文件一个月**：`YYYY-MM.json`（按裁决日期，维护者本地时区 UTC+08:00）。
- 顶层 `month`、文件名、每条 `date` 三者必须互相对得上（CI 强制）。
- 裁决历史**永不压缩**：即使条目后来被移除，旧的 approved 记录也保留 —— 可追溯「它曾经凭什么进来、又凭什么离开」。

## 字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | ✅ | 被裁决的技能 id（与 `index.json` 中的 id 一致） |
| `date` | ✅ | 裁决日期 `YYYY-MM-DD`，须落在文件月份内 |
| `decision` | ✅ | `approved` / `pending` / `rejected` |
| `decided_by` | ✅ | 裁决者（人或人或 AI，如实写；AI 参与时必须写明） |
| `basis` | ✅ | 非空字符串数组：**裁决依据**，人可读、可核对（如「≥3 个不同贡献者独立提交」「描述≥40 字」「来源为官方仓库」） |
| `evidence` | ❌ | `https://` URL 数组：可验证证据（PR / CI 运行 / Issue / 上游仓库） |
| `note` | ❌ | 备注：追溯登记、例外说明、更正说明 |

## CI 强制的双向一致（`python3 scripts/validate.py index.json --check-review-log --strict`）

1. **格式**：字段完整性、`decision` 取值、`date` 落在文件月份内、`basis` 非空、`evidence` 必须是 https URL；
   同一 `id` 在**一个月内可以有多条**记录（当月状态变更/更正，最新一条决定状态），但**同一天不能有两个不同裁决**（否则无法排序）；
2. **当前状态一致**（以每个 `id` 的**最新**裁决为准）：
   - 最新裁决 = `approved` ⇒ 该 id **必须**在 `index.json` 中；
   - 最新裁决 = `pending` / `rejected` ⇒ 该 id **不得**在 `index.json` 中；
3. **入库必有据**：`index.json` 中**每条**条目都必须至少有一条 `approved` 留痕（缺一条即红灯）。

> 为什么是「最新裁决」而不是「任何一条 approved 都得在库」：后者会让条目**一旦被合法移除**，历史记录就永久报错，与 append-only 的初衷相矛盾。

## 示例

```json
{
  "month": "2026-09",
  "note": "本月上下文（如机制启用、批量追溯登记）",
  "decisions": [
    {
      "id": "my-skill",
      "date": "2026-09-26",
      "decision": "approved",
      "decided_by": "axel286137079-dot（维护者）+ AI 审核助手",
      "basis": ["≥3 个不同贡献者独立提交，达成共识", "CI 机器预审通过"],
      "evidence": ["https://github.com/axel286137079-dot/skill-matcher-index/pull/12"],
      "note": "首次入库，source=community"
    }
  ]
}
```

## 追溯登记（2026-09 首批）

本机制**自 v4 启用**。v3 的 15 条目录条目是随 PR #1 一次性入库的，**当时没有逐条裁决记录**。

`2026-09.json` 中的 15 条 approved 属于**追溯登记**：

- 只登记**已发生的事实**（条目确实随 PR #1 进入公开目录）、依据（可核对的入库路径）与证据（PR 链接）；
- 在每条 `note` 中**如实标注「追溯登记」**，并写明「当时未保留逐条裁决记录」；
- 不编造当时的审核过程、评分或结论。

换句话说：追溯登记补的是**可追溯性**，不是**合法性叙事**。
